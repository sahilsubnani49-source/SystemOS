# Domain Models & Database Schemas

This document defines the schemas and domain models representing user context and dynamic items. These are written in generic Dart/Drift notation and FastAPI/Pydantic syntax.

---

## 1. Player Profile Context

Stores the user's real-life settings, preferences, and biographical inputs.

### Pydantic Model (FastAPI Backend)

```python
from pydantic import BaseModel, Field
from typing import List, Optional
from enum import Enum

class AIModelPreference(str, Enum):
    CLOUD = "cloud"
    LOCAL = "local"

class PlayerProfileContext(BaseModel):
    player_id: str = Field(..., description="Unique ID of the player")
    open_ended_bio: str = Field(
        ..., 
        description="User-defined bio containing life details, hobbies, relationships, etc."
    )
    model_preference: AIModelPreference = Field(
        default=AIModelPreference.LOCAL,
        description="Selects whether cloud API or local LLM (Ollama) is preferred."
    )
    active_dungeons: List[str] = Field(
        default=[],
        description="List of active dungeon keywords to pass to the AI."
    )
```

### Drift Table Definition (Flutter/SQLite Dart)

```dart
import 'drift/drift.dart';

class PlayerProfiles extends Table {
  TextColumn get playerId => text()();
  TextColumn get openEndedBio => text()();
  TextColumn get modelPreference => text().withDefault(const Constant('local'))();
  TextColumn get activeDungeons => text().map(const StringListConverter())(); // Serialized list

  @override
  Set<Column> get primaryKey => {playerId};
}
```

## 2. Dynamic Reward Items

Represents items dynamically generated by the AI engine.

### Pydantic Model (FastAPI Backend)

```python
from pydantic import BaseModel, Field
from typing import Dict, Optional

class SpecialEffect(BaseModel):
    name: str = Field(..., description="Name of the unique passive/active ability")
    trigger: str = Field(..., description="Action that triggers the effect")
    description: str = Field(..., description="Mechanics of the effect")

class DynamicItem(BaseModel):
    item_id: str = Field(..., description="Unique generated UUID for this inventory instance")
    name: str = Field(..., description="Dynamic item name")
    description: str = Field(..., description="Lore or flavor description")
    rarity: str = Field(..., description="Common, Rare, Epic, or Legendary")
    stat_modifiers: Dict[str, int] = Field(
        default={},
        description="Key-value mapping of attribute modifiers (e.g. {'perception': 5})"
    )
    special_effect: Optional[SpecialEffect] = Field(
        default=None,
        description="Special trigger/effect details for Legendary items"
    )
```

### Drift Table Definition (Flutter/SQLite Dart)

```dart
import 'drift/drift.dart';

class DynamicItems extends Table {
  TextColumn get itemId => text()();
  TextColumn get name => text()();
  TextColumn get description => text()();
  TextColumn get rarity => text()();
  
  // Stored as JSON strings in the SQLite database
  TextColumn get statModifiers => text().map(const JsonMapConverter())();
  TextColumn get specialEffect => text().nullable().map(const JsonEffectConverter())();

  @override
  Set<Column> get primaryKey => {itemId};
}
```
