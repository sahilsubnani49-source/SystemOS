# Download SystemOS for Android

Download the latest Android build of SystemOS:

[**⬇️ Download the latest APK**](https://github.com/sahilsubnani49-source/SystemOS/releases/latest/download/SystemOS.apk)

## Publishing a new build

1. Open [Releases](https://github.com/sahilsubnani49-source/SystemOS/releases) and create a new release (or edit the latest release).
2. Upload the APK build as a release asset named **`SystemOS.apk`**. The download link above always points to that asset on the latest release.
3. Publish the release. Anyone opening the link can then download the APK.

> The download link will work once a release with a `SystemOS.apk` asset has been published. For safety, download APKs only from releases you trust.
