# Kotodama: screenshots for background music

Kotodama is a pixel-art Japanese-learning RPG (iPhone portrait). Each screenshot below is one
area. The game already tags every map with a music slot; one track per slot covers the
whole game. Several maps share a slot (for example every Arc 4 mountain map uses `mountain`).
